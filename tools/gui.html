    Powering the Jetson down properly matters — the SD card is the boot device,
    and pulling batteries on a running filesystem is how you corrupt it.
    Always shut down from here before disconnecting anything.
  

  

    
    
    
  


  


  

    The 8x8 status panel draws well over an amp on solid red, which is wasted power
    on the bench — nobody needs to read the status colour from a metre away.
    Turning it off here darkens the panel and stops pixhawk_led_node;
    nothing else about the vehicle changes.
    Turn it back on before any run that has to show status.
    The Arduino's D7 kill input still outranks this: while that is high the panel
    is red whatever we send it.
